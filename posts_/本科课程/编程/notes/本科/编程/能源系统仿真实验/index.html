能源系统仿真实验

能源系统仿真实验

能源系统仿真用数学模型代替实际系统，在计算机上复现系统的稳态或动态过程。课程分四块：能源系统仿真的基本概念、MATLAB 与 Simulink 两个工具平台、机理与数据建模方法，最后是 PV-SOFC 系统仿真实验。

考核：出勤 \(10\%\)、课堂作业 \(30\%\)、项目大作业 \(60\%\)，没有闭卷笔试。

能源系统仿真概述

能源系统与仿真

能源系统是把能源资源转化为可利用能量并输送到终端用户的全过程，包含生产、转换、传输与分配、利用与存储、管理五个环节。

仿真是利用模型复现实际系统本质过程的方法。它的用途主要有五类：

  • 预测与规划
  • 优化设计与运行
  • 风险评估
  • 教育培训
  • 技术创新

能源系统有四个特征：复杂性、多样性、动态性、多功能性。

建模方法的分类

方法 说明
理论分析方法 从内部物理过程出发建立动态数学模型再求解，如用基尔霍夫定律分析电路、用热力学定律分析气体膨胀
实验测定方法 由实际输入输出数据确定模型，手段有系统辨识、参数估计、神经网络
经验归纳方法 时间序列、归纳推理（黑箱）、频域方法（由 \(G(s)\) 得匹配的 \(G(z)\)）、灰色理论（部分已知加部分未知）

按参数分布分为两类：

  • 集总参数模型：把系统看成一个质点，参数（温度、压力）处处均匀，只考虑外部影响、不描述内部状态，适合大尺度稳态简化分析
  • 分布参数模型：参数随空间连续变化，需要用偏微分方程描述

常用仿真软件：PSS/E 面向电力系统稳态与暂态，TRNSYS 面向建筑 HVAC 与可再生能源动态，MATLAB/Simulink 是通用平台。

稳态与动态

  • 稳态：经过一定时间后，输出或关键参数不再随时间变化
  • 动态：参数随时间持续变化
对比 稳态仿真 动态仿真
求解内容 长期运行状态 初始条件或外部条件变化下的时间响应
方法 热平衡与物平衡方程组（\(\sum\) 输入热量 \(=\sum\) 输出热量） 数值方法（有限差分、有限元）
优点 模型简单、计算快 能反映启停、扰动、状态转换
缺点 无法捕捉动态响应 计算量大、需要初值和参数

两者互为支持：稳态结果给动态仿真提供初值和初始状态，动态结果反过来验证并优化稳态结果。

动态与稳态的差别主要体现在惯性上：热惯性、容积惯性、机械惯性。稳态问题通常不考虑惯性。

判断该用哪种模型，有两条判据：模型是否含时间变量；有没有考虑惯性。

MATLAB 基础

工作环境

MATLAB 名称来自 Matrix Laboratory，基本数据单位是矩阵。界面分四区：当前文件夹、命令行窗口（提示符 >>）、工作区、编辑器。

常用命令：

命令 作用
clc 清屏，不清除变量
clear 清除工作区变量
close all 关闭所有图窗
Ctrl+C 强制中断运行中的程序

没有返回值的语句，结果送到默认变量 ans。

数据类型与变量

  • 默认 double 为 64 位、8 字节，另有 uint8、uint16 等整型
  • 保留字：pi、eps（\(2.2204\times10^{-16}\)）、inf、NaN（\(0/0\)、\(\mathrm{Inf}/\mathrm{Inf}\) 的结果）、i、j（一旦当纯虚常量用，就不能再当循环变量）
  • 变量命名：必须字母开头，可含字母、数字、下划线，大小写敏感，无需声明，赋值即创建

矩阵与数组

  • 矩阵是线性代数概念，只存数值；数组是计算机概念，可存数值、字符、逻辑
  • 标量、行向量、列向量分别是 \(1\times1\)、\(1\times n\)、\(n\times1\)

三种创建方式：

  1. 元素列举：逗号或空格分列，分号分行，中括号包裹
  2. 专用函数：zeros、ones、rand，以及矩阵拼接
  3. 冒号序列：first:step:last，步长可正可负、可为小数

下标访问的三条易错规则：

  • 下标从 \(1\) 开始
  • 矩阵按列存储
  • 下标越界会自动扩展，并用 \(0\) 填充

size(X) 返回行数和列数组成的行向量，size(X,dim) 取某一维，length(X) 返回最大维的长度。

运算

运算 说明
按位与、按位或 用于数组之间
短路与、短路或 用于表达式之间，有短路特性
/、\ 右除、左除；\(5/2=2.5\)，\(5\backslash2=0.4\)，也可用于矩阵
点运算 .*、./、.^ 逐元素作用，要求两操作数同维同长
矩阵运算 遵循线性代数规则
' 与 .' 共轭转置与不共轭转置

脚本与函数

  • 脚本 .m：直接运行，变量全部进入工作区；实时脚本 .mlx 把代码与输出图形同屏
  • 函数：有入口和出口参数，文件名必须与函数名相同，不能独立运行，只能在别处调用

内置函数库分四类：初等数学、线性代数、数值积分与微分方程求解、傅里叶分析与滤波。

流程控制

语句 要点
if / elseif / else 条件分支
switch / case case 后不能含关系运算符，也不能加 break

break / continue 跳出整个循环 / 跳过本次剩余语句

绘图

plot(X1,Y1,LineSpec1,...) 一条语句可以画多条曲线，\(X\)、\(Y\) 必须等长。LineSpec 由线型、标记、颜色组成，参数必须用单引号括起；也可以用名值对设置属性。之后再叠加标题、坐标轴、图例、网格。

  • subplot(m,n,p) 把窗口分成 \(m\times n\) 个子图，序号按行排列
  • plot3(x,y,z) 画三维曲线
  • stem() 画离散序列

Simulink 仿真平台

模块与模块库

模块（Block）是搭建仿真模型的基本单位。模块库分基本模块库和扩展模块库（工具箱），库浏览器带搜索栏。

常用模块：

类别 模块
信号源 Sources Constant、Step、Sine、Pulse、Random
接收器 Sinks Scope、Display、To Workspace、To File
连续 Continuous Integrator、Derivative、Transfer Fcn
数学运算 Sum、Gain、Product、Fcn
信号路由 Mux、Demux

注意：接收器子库的模块只有输入端，没有输出端。

建模流程

  1. 想清楚输入是什么、用什么模块实现
  2. 想清楚要做哪些运算、用什么模块
  3. 想清楚输出是什么、怎么显示
  4. 新建空白模型并保存，从库浏览器拖入模块
  5. 连线、设参数、运行仿真

编辑操作：滚轮平移缩放、右键拖动复制、Ctrl+R 旋转、Ctrl+I 翻转、双击打开参数界面。布局上坚持左输入右输出，尽量在一条直线上分布。

求解器

Simulink 在指定时间范围内按给定步长计算系统状态，每次循环是一个”仿真步”。求解器（Solver）就是体现特定求解方法的程序。

分类 说明
固定步长 仿真过程中步长固定，没有误差控制
变步长 步长由求解器自动确定，通过增减步长满足误差容限
离散求解器 适用于离散系统
连续求解器 适用于连续系统

常见变步长求解器：ode45（默认，适用于多数非刚性系统）、ode15s（刚性系统）、ode23、ode113。

选择原则：一般先用 auto，让系统自动选择并尽量取大步长；结果不满足要求时再手动比较不同求解器。对变步长求解器，结果应落在指定的容差范围内。

采样时间

模块的 Sample time 参数决定执行速度：

  • 设为 \(0\)：以求解器步长计算，输出连续信号
  • 设为非零：以该采样时间作为步长，输出离散信号

运行仿真

  • 图形界面：点击运行按钮；运行键变成暂停键
  • 命令行：sim() 函数

数据导出

方式 说明

动态系统仿真步骤

  1. 把微分方程最高阶项的系数化为 \(1\)，等式左侧只保留最高阶项
  2. 微分方程的阶数就是积分模块的数量
  3. 从积分模块开始画仿真流程图，确定模块和信号流向
  4. 按流程图在 Simulink 中建模，运行并分析动态特性

能源系统机理建模

守恒方程

守恒方程描述系统内部物质与能量的守恒，分质量、动量、能量三类，用微分方程描述系统行为的变化。

取一个控制体，基本关系是

\[ \text{变化的}=\text{得到的}-\text{失去的} \]

质量守恒

\[ \frac{\mathrm{d}M}{\mathrm{d}t}-m_\mathrm{in}+m_\mathrm{ex}=0 \]

  • 稳态时 \(\dfrac{\mathrm{d}M}{\mathrm{d}t}=0\)，于是 \(m_\mathrm{in}=m_\mathrm{ex}\)
  • 对圆柱形储液罐 \(M=\rho Sh\)，有

\[ \rho S\frac{\mathrm{d}h}{\mathrm{d}t}-m_\mathrm{in}+m_\mathrm{ex}=0 \]

能量守恒

单位质量的能量为

\[ E=e+\frac{1}{2}V^2+gz+\frac{p}{\rho} \]

四项分别是内能、动能、势能、静压能。

控制体的能量方程

\[ \frac{\mathrm{d}E_{CV}}{\mathrm{d}t}=Q-W+m_\mathrm{in}h_\mathrm{in}-m_\mathrm{ex}h_\mathrm{ex} \]

  • 稳态时 \(\dfrac{\mathrm{d}E_{CV}}{\mathrm{d}t}=0\)，有 \(Q-W+m_\mathrm{in}h_\mathrm{in}-m_\mathrm{ex}h_\mathrm{ex}=0\)
  • 若系统不做体积功且绝热，则能量变化只由进出口焓差决定

开放系统（开口系统）要考虑质量流动携带的能量；封闭系统没有物质交换，只有功和热。

封闭系统与微分形式

\[ \Delta U=Q-W \]

单位工质 \(\Delta u=q-w\)，微元过程

\[ \mathrm{d}u=\delta q-\delta w \]

体积功（压强功）

\[ \delta w=p\,\mathrm{d}V \]

四个典型过程：

过程 条件 结果
绝热 \(\delta q=0\) \(\mathrm{d}u=\delta w\)
等温 \(T\) 不变，理想气体 \(\mathrm{d}u=0\) \(Q=W\)
等容 \(\mathrm{d}V=0\) \(\mathrm{d}u=\delta q\)
等压 \(p\) 恒定 \(\Delta U=Q-p\Delta V\)

传热的三种方式

方式 规律
热传导 傅里叶定律 \(q=-kA\dfrac{\mathrm{d}T}{\mathrm{d}r}\)
对流传热 牛顿冷却公式 \(q=hA\left(t_w-t_f\right)\)，\(h\) 与流动类型有关
辐射传热 斯特藩-玻尔兹曼定律 \(q=\sigma A\left(T_1^4-T_2^4\right)\)

能源系统仿真中考虑辐射的情况比较少。

综合起来

\[ \mathrm{d}u=\delta q_{cn}+\delta q_{cv}+\delta q_r-p\delta V-\delta w_{\text{其他}} \]

换热过程集总模型

以管内流体被外部高温热源加热为例，假设：

  • 管壁外高温热源温度 \(T_h\) 不变
  • 不考虑管壁传热过程，管内流体参数分布均匀

列四个方程：

\[ \left\{ \begin{aligned} &\text{热平衡：}&& m_{cv}c_p\frac{\mathrm{d}T_\mathrm{ex}}{\mathrm{d}t}=Q+m_\mathrm{in}c_pT_\mathrm{in}-m_\mathrm{ex}c_pT_\mathrm{ex}\\ &\text{连续性：}&& m_\mathrm{in}=m_\mathrm{ex}=\rho Au\\ &\text{对流传热：}&& Q=hA\left(T_h-T_\mathrm{ex}\right)\\ &\text{质量关联：}&& m_{cv}=\rho V \end{aligned} \right. \]

合并得

\[ \rho c_pV\frac{\mathrm{d}T_\mathrm{ex}}{\mathrm{d}t} =hA\left(T_h-T_\mathrm{ex}\right)+m_\mathrm{in}c_p\left(T_\mathrm{in}-T_\mathrm{ex}\right) \]

三项分别是能量变化率、对流传热量、热流携带量。

算例：\(T_h=35\ ^\circ\mathrm{C}\)，\(T_\mathrm{in}=10\ ^\circ\mathrm{C}\)，\(R=0.2\ \mathrm{m}\)，\(L=1\ \mathrm{m}\)。

流体 \(c_p\) \(\rho\) \(h\)
空气 \(1.005\ \mathrm{kJ/(kg\cdot K)}\) \(1.2\ \mathrm{kg/m^3}\) \(0.15\ \mathrm{kW/(m^2\cdot K)}\)
水 \(4.2\ \mathrm{kJ/(kg\cdot K)}\) \(1000\ \mathrm{kg/m^3}\) \(1.0\ \mathrm{kW/(m^2\cdot K)}\)

两者的时间常数相差几个数量级，所以空气的出口温度响应快、水慢。

微型燃机电制冷系统模型

微燃机燃烧天然气发电，余热驱动制冷机。动态模型把系统简化为一阶惯性环节：

  • 变量：\(P_{mt}\) 微燃机功率，\(G_{fm}\) 燃气流率，\(T_{abs}\) 制冷机供水温度
  • 常数：\(k_1=-6.862\times10^{-5}\)、\(k_2=2.144\times10^{4}\)、\(k_3=-1.128\times10^{2}\)、\(k_4=-3.863\times10^{-2}\)
  • 时间常数：\(\tau_{mt}=20\)、\(\tau_{abs}=130\)

模型形式为

\[ \left\{ \begin{aligned} \tau_{mt}\frac{\mathrm{d}P_{mt}}{\mathrm{d}t}&=k_1G_{fm}^2+k_2G_{fm}+k_3-P_{mt}\\ \tau_{abs}\frac{\mathrm{d}T_{abs}}{\mathrm{d}t}&=k_4P_{mt}-T_{abs} \end{aligned} \right. \]

稳态时令导数项为零，得到初值

\[ P_0=k_1G_0^2+k_2G_0+k_3,\qquad T_0=k_4P_0 \]

用这个初值设置积分器，系统就能从平衡状态出发，再施加阶跃扰动观察动态响应。

数据驱动与混合建模

数据驱动建模

当显式物理规律难以获得时，可以直接从数据中学习输入—输出映射，不依赖机理先验知识。常用模型：线性回归、支持向量机（SVM）、长短期记忆网络（LSTM）、自回归网络（NARX）。

流程：

  1. 数据采集与预处理：清洗、去噪、标准化
  2. 特征工程：把原始数据转换为更能表达问题本质的特征
  3. 模型选择、设计与训练：在参数空间中寻找使预测偏差最小的参数
  4. 模型验证：用未参与训练的数据测试泛化能力
  5. 模型评估：用指标量化精度

预处理常做异常值剔除、缺失值插补和 Z-score 归一化

\[ z=\frac{x-\mu}{\sigma} \]

它表示数据点距均值多少个标准差，用于消除量纲差异。

特征工程的作用：提升模型性能、加速训练、增强泛化能力、适应模型假设。

欠拟合与过拟合

状态 表现
欠拟合 模型过于简单，训练集和测试集误差都偏高，泛化能力差
适拟合 复杂度与数据规律匹配，训练误差和测试误差都低且接近
过拟合 模型复杂度过高，训练误差接近零，测试误差明显增大

评估指标

\[ \mathrm{RMSE}=\sqrt{\frac{1}{n}\sum_{i=1}^{n}\left(y_i-\hat y_i\right)^2} \]

\[ \mathrm{MAE}=\frac{1}{n}\sum_{i=1}^{n}\left|y_i-\hat y_i\right| \]

\[ R^2=1-\frac{\sum\left(y_i-\hat y_i\right)^2}{\sum\left(y_i-\bar y\right)^2} \]

RMSE 对大误差更敏感，MAE 更稳健，\(R^2\) 越接近 \(1\) 拟合越好。

机理与数据混合建模

纯机理模型在复杂系统中难以精确，纯数据模型缺乏可解释性。混合建模把两者结合，常见策略：

  • 机理模型为主，数据模型修正残差
  • 数据模型为主，机理约束参数范围
  • 串联：机理模型输出作为数据模型输入
  • 并联：两者加权融合

混合建模既能保持物理可解释性，又能提高精度，是能源系统建模的常用方向。

PV-SOFC 系统仿真实验

这一章是综合实验：先建立光伏电池的数学模型，再建立固体氧化物燃料电池（SOFC）的电压与热模型，最后把两者组合成 PV-SOFC 冷热电联供系统。

光伏发电概述

光生伏特效应

光伏发电利用半导体材料制成的太阳能电池，在吸收太阳光后产生伏特效应（光生伏特效应），把光能直接转变为电能。

机理分四步：

  1. 光照激发：P-N 结内的电子受光激发，产生额外的电子—空穴对
  2. 形成载流子：电子和空穴的产生率大于复合率，形成非平衡载流子（光生载流子）
  3. 迁移与内建电场：载流子迁移，形成内建电场
  4. 光生电动势：P 区和 N 区因载流子迁移，产生与内建电场方向相反的光生电动势场

发展历程

年份 事件
1839 贝克雷尔（Becquerel）发现光生伏特效应
1954 贝尔实验室制成第一块实用单晶硅电池，效率 \(6\%\)
20 世纪 70 年代 能源危机与污染问题推动光伏发展
90 年代 各国推出屋顶计划、上网电价，产业快速成长
2023 全球新增装机 \(425\ \mathrm{GW}\)，中国 \(263\ \mathrm{GW}\)，占约 \(62\%\)

优缺点

优点七项：无枯竭危险、安全可靠、无噪声无污染、不受资源分布地域限制、可就地发电供电、无需消耗燃料和架设输电线路、建设周期短。

缺点四项：

  • 能量分布密度低、占地面积大（地面辐射度最高约 \(1.2\ \mathrm{kW/m^2}\)，多数地区低于 \(1\ \mathrm{kW/m^2}\)）
  • 转换效率低、间歇性工作（实验室多结电池 \(28\%\sim30\%\)，商业晶硅电池 \(20\%\sim25\%\)）
  • 受气候、环境和地域因素影响大
  • 光伏板制造过程高污染、高能耗（硅砂需提纯到 \(99.9999\%\) 以上）

应用形式

形式 特点
离网系统 组件、控制器、蓄电池、负载组成独立电源
集中式并网电站 容量大、占地广、建在偏远地区，需专业人员维护
分布式发电 容量小、接入电压低、靠近负荷，对电网影响小
BIPV 光伏建筑一体化，组件与建筑同步设计
BAPV 建筑附加光伏，组件附加安装在屋面

光伏电池模型

等效电路

理想光伏电池可以看成恒流源并联一个二极管：

  • 光生电流 \(I_{ph}\)：光照射产生的电流，大小与辐照度成正比
  • 暗电流 \(I_D\)：无光照时，外电压作用下 P-N 结的漏电流，方向与光生电流相反

实际电池还要考虑两个电阻：

  • 串联电阻 \(R_s\)：由电池体电阻、表面电阻、电极导体电阻、电极与硅表面接触电阻组成，数值很小（约 \(10^{-3}\ \Omega\)）
  • 并联电阻 \(R_{sh}\)：由硅片边缘不清洁或体内缺陷导致，数值很大（约 \(10^3\ \Omega\)）

特性方程

由 KCL 和 KVL 得

\[ I=I_{ph}-I_0\left[\exp\left(\frac{q\left(V+IR_s\right)}{AKT}\right)-1\right] -\frac{V+IR_s}{R_{sh}} \]

式中 \(I_0\) 为二极管反向饱和电流，\(q\) 为电子电量，\(k\) 为玻尔兹曼常数（\(1.38\times10^{-23}\ \mathrm{J/K}\)），\(T\) 为绝对温度，\(A\) 为二极管因子（取 \(1\sim2\)）。

这是一个超越方程，含 \(I_{ph}\)、\(I_0\)、\(R_s\)、\(A\)、\(R_{sh}\) 五个未知参数，直接求解困难。厂家通常只给出标准状况下的四个参数：

  • 短路电流 \(I_{sc}\)
  • 开路电压 \(V_{oc}\)
  • 最大功率点电流 \(I_m\)
  • 最大功率点电压 \(V_m\)

标准状况：\(T=25\ ^\circ\mathrm{C}\)、\(P=1\ \mathrm{atm}\)、\(S_{ref}=1\ \mathrm{kW/m^2}\)。

四参数工程模型

制造工艺较好的电池可以近似认为 \(R_s\approx0\)、\(R_{sh}\to\infty\)，方程简化为

\[ I=I_{sc}-C_1I_{sc}\left[\exp\left(\frac{V}{C_2V_{oc}}\right)-1\right] \]

用两个无量纲系数 \(C_1\)、\(C_2\) 代替含温度和二极管因子的物理量。这样 \(V=0\) 时自动得到 \(I=I_{sc}\)，剩下开路点和最大功率点两个条件正好确定两个未知数。

第一步：用最大功率点

代入 \(V=V_m\)、\(I=I_m\)，并利用 \(V_m/(C_2V_{oc})\gg1\)，略去 \(-1\)，得

\[ C_1=\left(1-\frac{I_m}{I_{sc}}\right)\exp\left(-\frac{V_m}{C_2V_{oc}}\right) \]

方程里还含 \(C_2\)，不能直接算。

第二步：用开路点

代入 \(V=V_{oc}\)、\(I=0\)，同样略去 \(-1\)，得

\[ C_1=\left(1-\frac{I_{sc}}{I_{sc}}\right)\exp\left(\frac{V_{oc}}{C_2V_{oc}}\right) \]

与第一步联立，消去 \(C_1\)，取对数解出

\[ C_2=\frac{\dfrac{V_m}{V_{oc}}-1}{\ln\left(1-\dfrac{I_m}{I_{sc}}\right)} \]

再代回求 \(C_1\)。

符号检查：\(V_m<V_{oc}\) 使分子为负，\(I_m<I_{sc}\) 使对数为负，所以 \(C_2>0\)。

计算流程：

  1. 读取铭牌 \(I_{sc}\)、\(V_{oc}\)、\(I_m\)、\(V_m\)
  2. 先算 \(C_2\)
  3. 再算 \(C_1\)
  4. 代入 \(I(V)\)，\(V\) 从 \(0\) 取到 \(V_{oc}\)

温度与辐照修正

实际工况不是标准状况，需要修正：

  • 短路电流随辐照度成正比，并随温度上升而增大（温度系数 \(a\)）
  • 开路电压随温度上升而下降（温度系数 \(b\)），并随辐照度按对数规律上升
  • 电池温度由环境温度和辐照度决定 \(T=T_{air}+kS\)

课件算例：\(V_{oc}=21.5\ \mathrm{V}\)、\(I_{sc}=2.5\ \mathrm{A}\)、\(I_m=2.33\ \mathrm{A}\)、\(V_m=17.2\ \mathrm{V}\)，\(a=0.0025\ \mathrm{A/^\circ C}\)、\(b=0.0028\ \mathrm{V/^\circ C}\)、\(R_s=0.005\ \Omega\)、\(T_{air}=20\ ^\circ\mathrm{C}\)、\(k=0.03\ ^\circ\mathrm{C\cdot m^2/W}\)。

光伏阵列与旁路二极管

一个组件由若干电池串联，组件再串并联成阵列。仿真模型用三个子模块串联，每个子模块由 \(20\) 个电池串联：

子模块 辐照度 模拟工况
1 \(1000\ \mathrm{W/m^2}\) 标准光照
2 \(300\ \mathrm{W/m^2}\) 部分遮挡
3 \(600\ \mathrm{W/m^2}\) 部分遮挡

每个子模块配一个旁路二极管：某个模块被遮挡时，旁路二极管提供电流通路，避免模块因反向电流损坏，并维持整个阵列的电流输出。

仿真的输出是 \(I\)-\(V\) 和 \(P\)-\(V\) 特性曲线，最大功率点对应的电压和电流是设计与控制最关键的参考值。

固体氧化物燃料电池概述

定义与原理

燃料电池是按电化学原理，在等温条件下把燃料的化学能直接转换为电能的装置。只要保持燃料和氧化剂供给，就能连续发电。

SOFC 使用固体氧化物（通常是氧化钇稳定的氧化锆 YSZ）作电解质，在 \(600\sim1000\ ^\circ\mathrm{C}\) 的高温下工作。

工作过程：

位置 过程
阴极（空气极） \(\mathrm{O_2+4e^-\to2O^{2-}}\)
电解质 \(\mathrm{O^{2-}}\) 经氧空位从阴极迁移到阳极
阳极 \(\mathrm{H_2+O^{2-}\to H_2O+2e^-}\)
外电路 电子经负载做功，形成回路

记忆要点：离子在电池内部从阴极走到阳极，电子在电池外部从阳极走到阴极。

为什么效率高

传统热机是”化学能 \(\to\) 热能 \(\to\) 机械能 \(\to\) 电能”，受卡诺循环限制，效率不超过 \(50\%\)。燃料电池是”化学能 \(\to\) 电能”直接转换，不经过热功转换，可逆热力学效率可达 \(70\%\) 左右。

发展历程

年份 事件
1899 能斯特（Nernst）发现固态氧离子导体（\(85\%\) \(\mathrm{ZrO_2}\) + \(15\%\) \(\mathrm{Y_2O_3}\)）
1937 Baur 和 Preis 提出用固体氧化物作电解质
1960–70 年代 西屋公司提出并发展管式 SOFC
1990 年代 发电效率突破 \(50\%\)
2000 年至今 小型化与商业化

\(\mathrm{Y_2O_3}\) 掺入 \(\mathrm{ZrO_2}\) 后，立方相在低温下稳定存在，并引入氧空位，使 \(\mathrm{O^{2-}}\) 能在晶格中迁移。

平板式与管式

结构 特点
平板式 阳极、电解质、阴极、连接体构成重复单元，层状堆叠；功率密度高、制造工艺成熟、热管理好
管式 同心圆管，管内空气、管外燃料；无需高温密封、结构稳定抗热循环，但功率密度低、成本高

优缺点

优点：排放低（燃料电池的 \(\mathrm{CO_2}\) 排放约 \(270\ \mathrm{kg/MWh}\)，煤约 \(800\)）、效率高（\(45\%\sim50\%\)，与涡轮联用可达 \(60\%\sim70\%\)）、燃料适应性广、高温余热可梯级利用。

缺点多源于高温运行：

  • 工作温度高（\(600\sim1000\ ^\circ\mathrm{C}\)），材料老化、寿命缩短
  • 启动时间长，冷启动慢
  • 对材料要求高，成本高
  • 高温高压下密封困难

SOFC 建模

零维集总模型的三条假设

  1. 所有气体均为理想气体
  2. 分压均一：每种气体只定义一个分压
  3. 温度均一：整个电堆只有一个温度 \(T\)

把阳极、电解质、阴极（PEN）视为一个整体，电堆与流道作为控制体。

Nernst 电压

燃料电池能输出的理论最大电动势称为 Nernst 电压

\[ V_\mathrm{Nernst}=E_0+\frac{RT}{2F}\ln\left(\frac{p_{\mathrm{H_2}}p_{\mathrm{O_2}}^{1/2}}{p_{\mathrm{H_2O}}}\right) \]

其中

  • \(E_0\) 为标准电动势，是温度的函数：\(E_0=1.273-2.7645\times10^{-4}T\)
  • \(R=8.314\ \mathrm{J/(mol\cdot K)}\)，\(F=96485\ \mathrm{C/mol}\)
  • 分压取集总模型的单值，单位 \(\mathrm{Pa}\)

反应物分压越高，Nernst 电压越高。

三种电压损失

实际输出电压低于 Nernst 电压，差值来自三种极化

\[ V=V_\mathrm{Nernst}-V_\mathrm{act}-V_\mathrm{ohm}-V_\mathrm{conc} \]

活化极化

电极反应某一步速率较慢，需要额外电压驱动，称为活化极化（电化学极化）。低电流密度区电压下降最明显。

\[ V_\mathrm{act}=a+b\log i \]

系数随温度变化

\[ \left\{ \begin{aligned} a&=0.343333-0.000275T\\ b&=0.0153+2.5917\times10^{-5}T-1.0804\times10^{-8}T^2 \end{aligned} \right. \]

这是 Tafel 形式：活化损失随电流密度对数增长。

欧姆极化

电解质离子传导电阻和电极、连接件电子传导电阻引起，与电流近似成正比

\[ V_\mathrm{ohm}=IR_\mathrm{ohm} \]

内阻为各层电阻串联

\[ R_\mathrm{ohm}=\frac{\tau_\mathrm{anode}}{\sigma_\mathrm{anode}} +\frac{\tau_\mathrm{electrolyte}}{\sigma_\mathrm{electrolyte}} +\frac{\tau_\mathrm{cathode}}{\sigma_\mathrm{cathode}} \]

各层电导率随温度变化

\[ \left\{ \begin{aligned} \frac{1}{\sigma_\mathrm{anode}}&=2.98\times10^{-5}\exp\left(-\frac{1392}{T}\right)\\ \frac{1}{\sigma_\mathrm{cathode}}&=8.11\times10^{-5}\exp\left(-\frac{600}{T}\right)\\ \frac{1}{\sigma_\mathrm{electrolyte}}&=2.94\times10^{-5}\exp\left(-\frac{10350}{T}\right) \end{aligned} \right. \]

厚度取阴极 \(1\ \mathrm{mm}\)、阳极 \(1\ \mathrm{mm}\)、电解质 \(2\ \mathrm{mm}\)。

浓差极化

高电流时反应气体供应跟不上，电极界面浓度下降，导致电压损失

\[ V_\mathrm{conc}=\frac{RT}{\alpha nF}\ln\left(\frac{i_L}{i_L-i}\right) \]

其中 \(\alpha=1\) 为传质反应速率常数，\(n=2\) 为转移电子数，\(i_L\) 为极限电流密度。当 \(i\to i_L\) 时，浓差损失急剧增大。

组分守恒

电化学反应很快，组分守恒方程近似按稳态处理：

\[ \left\{ \begin{aligned} \frac{\mathrm{d}m_{\mathrm{H_2},an}}{\mathrm{d}t} &=m_{\mathrm{H_2},an,in}-m_{\mathrm{H_2},an,ex}-\Delta m_{\mathrm{H_2},reacted}\approx0\\ \frac{\mathrm{d}m_{\mathrm{O_2},ca}}{\mathrm{d}t} &=m_{\mathrm{O_2},ca,in}-m_{\mathrm{O_2},ca,ex}-\Delta m_{\mathrm{O_2},reacted}\approx0 \end{aligned} \right. \]

由法拉第定律，反应消耗与生成速率为

\[ \left\{ \begin{aligned} \Delta m_{\mathrm{H_2}}&=N_cM_{\mathrm{H_2}}\frac{I}{2F}\\ \Delta m_{\mathrm{O_2}}&=N_cM_{\mathrm{O_2}}\frac{I}{4F}\\ \Delta m_{\mathrm{H_2O}}&=N_cM_{\mathrm{H_2O}}\frac{I}{2F} \end{aligned} \right. \]

其中 \(N_c\) 为电池片数，\(I/(2F)\) 为单电池氢气消耗的摩尔数。

用途：由组分守恒算出出口组分含量与分压，再算 Nernst 电压，最后算电池电压。

能量守恒与热模型

电堆温度是动态的，能量守恒方程为

\[ N_c\rho V_c c_p\frac{\mathrm{d}T_\mathrm{ex}}{\mathrm{d}t} =\sum_i\dot n_{i,in}h_i\left(T_\mathrm{in}\right) -\sum_i\dot n_{i,ex}h_i\left(T_\mathrm{ex}\right) -\left(1-\beta\right)\frac{N_cI}{2F}\Delta H_r-IV \]

等式右边五项依次是：储热变化、入口焓、出口焓、反应放热（扣除热损失）、输出电功。

  • \(\beta\) 为热损失系数，绝热时取 \(0\)
  • \(\Delta H_r\) 为氢气的摩尔反应热（约 \(-2.418\times10^5\ \mathrm{J/mol}\)）
  • \(V_c=A_cd_c\) 为单电池体积
  • 假设出口温度等于电堆温度 \(T_\mathrm{ex}=T\)

各气体焓值是温度的多项式，例如

\[ h_{\mathrm{H_2}}=29.11T-\frac{0.1916\times10^{-2}}{2}T^2 +\frac{0.4003\times10^{-5}}{3}T^3-\frac{0.8704\times10^{-9}}{4}T^4 \]

氧气、水蒸气、氮气有各自的多项式系数。

建模步骤

电压模型：

  1. 由电流 \(I\) 算电流密度 \(i=I/A_c\)，再算氢气、氧气、水蒸气的反应量
  2. 由组分守恒算阴、阳极出口各组分质量流量，以及燃料利用系数 \(FU=\Delta n_{\mathrm{H_2}}/n_{\mathrm{H_2},in}\)、氧气利用系数 \(OU=\Delta n_{\mathrm{O_2}}/n_{\mathrm{O_2},in}\)
  3. 由出口流量和分压定律算各组分分压
  4. 由温度算 \(V_\mathrm{Nernst}\)、\(V_\mathrm{ohm}\)、\(V_\mathrm{act}\)、\(V_\mathrm{conc}\)，最后得 \(V\)

热模型：

  1. 计算 \(N_c\rho V_c c_p\)，把微分项系数化为 \(1\)
  2. 计算进出口焓值
  3. 计算反应热与输出功率
  4. 计算积分项
  5. 与电压方程耦合，完成仿真

算例参数

电压模型算例：\(T=1160\ \mathrm{K}\)，\(I=60\ \mathrm{A}\)，\(A_c=100\ \mathrm{cm^2}\)，\(p_{in}=101325\ \mathrm{Pa}\)，\(i_L=2\ \mathrm{A/cm^2}\)，\(N_c=1\)，氢气进口质量流量 \(8.4\times10^{-7}\ \mathrm{kg/s}\)，空气进口质量流量 \(4.8249\times10^{-5}\ \mathrm{kg/s}\)。

热模型算例：\(c_p=200\ \mathrm{J/(kg\cdot K)}\)，\(\rho=3755\ \mathrm{kg/m^3}\)，\(d_c=2\ \mathrm{cm}\)，\(\Delta H_r=-2.418\times10^5\ \mathrm{J/mol}\)，\(T_\mathrm{in}=800\ \mathrm{K}\)，初始电堆温度 \(1000\ \mathrm{K}\)。

实验作业

  1. 建立 SOFC 电压模型，研究电堆温度 \(900\)、\(1000\)、\(1100\ \mathrm{K}\) 下的 \(i\)-\(V\) 与 \(i\)-\(P\) 曲线
  2. 搭建 SOFC 热模型并与电压模型耦合，研究电流 \(40\)、\(60\)、\(80\ \mathrm{A}\) 下电堆温度的变化
