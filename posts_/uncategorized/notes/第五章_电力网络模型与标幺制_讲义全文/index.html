P5　5.2 电力系统的标幺制

一、基准值的选择和标幺值计算

1、标幺值定义

\[\text{标幺值(per unit value)} = \frac{\text{有名值(actual value)}}{\text{基准值(base value)}}\]

2、基准值选择——一般选定两个基准值：基准功率 S_B、基准电压 U_B

\[\begin{cases} I_B = \dfrac{S_B}{\sqrt{3}\,U_B} \\[8pt] Z_B = \dfrac{U_B^2}{S_B} \end{cases}\]

3、标幺值计算

\[S_* = \frac{S}{S_B};\quad P_* = \frac{P}{S_B};\quad Q_* = \frac{Q}{S_B};\quad U_* = \frac{U}{U_B};\quad I_* = \frac{I}{I_B};\quad Z_* = \frac{Z}{Z_B} = Z\cdot\frac{S_B}{U_B^2}\]

4、三相总功率、单相功率标幺值相等；线电压、相电压标幺值相等

P6　二、统一基准值的选定和标幺值换算

  • 发电机、变压器和电抗器的阻抗（铭牌参数）
  • 标幺值的统一：选定统一基准值
  • 换算准则：

\[\text{铭牌值} \xrightarrow{\text{额定参数}} \text{有名值} \xrightarrow{\text{统一基准值}} \text{标幺值}\]

P7　三、多电压等级系统等值电路

1、逐级归算法

  • 电压级归算
  • 无论采用有名值还是标幺值，对多电压等级网络，都须将参数或变量归算至同一电压级 ➡ 基本级
  • 通常取网络中最高电压级为基本级

（1）有名值的电压级归算

\[\begin{cases} Z' = Z(k_1k_2k_3\cdots)^2 \\[6pt] Y' = Y\left(\dfrac{1}{k_1k_2k_3\cdots}\right)^2 \\[8pt] U' = U(k_1k_2k_3\cdots) \\[6pt] I' = I\left(\dfrac{1}{k_1k_2k_3\cdots}\right) \end{cases}\]

P8　（2）标幺值的电压级归算

\[Z_* = \frac{Z}{Z_B} = \frac{\text{该阻抗实际有名值}}{\text{统一基准值}}\]

两种途径

  • 参数有名值归算至基本级： \[Z \to Z' \to Z_* = \frac{Z'}{Z_B} = \frac{Z(k_1k_2k_3\cdots)^2}{Z_B}\]
  • 统一基准值换算到该阻抗所在电压等级的基准值： \[Z_B \to Z_B' \to Z_* = \frac{Z}{Z_B'} = \frac{Z}{Z_B\left(\frac{1}{k_1k_2k_3\cdots}\right)^2}\]

P9　有名值 / 标幺值电压级归算对比算例

系统：220kV — T1(220/525) — 500kV(L) — T2(500/121) — 110kV — T3(110/38.5) — 35kV — T4(35/11) — 10kV，10kV 侧 R = 10 Ω 归算至 500kV 基本级。

有名值电压级归算（10kV 侧参数归算至 500kV 电压等级）

\[U' = U(k_2k_3k_4) = 10\cdot\frac{35}{11}\cdot\frac{110}{38.5}\cdot\frac{500}{121} = 375.66\ \text{kV}\]

\[R' = R(k_2k_3k_4)^2 = 10\cdot\left(\frac{35}{11}\cdot\frac{110}{38.5}\cdot\frac{500}{121}\right)^2 = 14112\ \Omega\]

标幺值电压级归算（S_B = 100 MVA, U_B = 500 kV）

\[R' = 14112\ \Omega,\qquad Z_B = \frac{U_B^2}{S_B} = \frac{500^2}{100} = 2500\ \Omega,\qquad R_* = \frac{R'}{Z_B} = \frac{14112}{2500}\approx 5.6\]

\[Z_B' = Z_B\left(\frac{1}{k_2k_3k_4}\right)^2 = \frac{2500}{\left(\frac{35}{11}\cdot\frac{110}{38.5}\cdot\frac{500}{121}\right)^2} = 1.77\ \Omega,\qquad R_* = \frac{R}{Z_B'} = \frac{10}{1.77}\approx 5.6\]

两种途径结果一致（均约 5.6）。

P11　2、各选电压法

\[Z_{1*} = Z_1\frac{S_B}{U_{B1}^2}\qquad K_* = \frac{U_{I*}}{U_{II*}} = \frac{U_{It}/U_{B1}}{U_{IIt}/U_{B2}}\qquad Z_{2*} = Z_2\frac{S_B}{U_{B2}^2}\]

关键：选择各级电压基准值

基准值选法 关系式 标幺变比
按变压器实际变比选择 \(U_{B1} = \dfrac{U_{It}}{U_{IIt}}U_{B2}\) \(K_* = \dfrac{U_{It}/U_{B1}}{U_{IIt}/U_{B2}} = 1\)
按变压器额定变比选择 \(U_{B1} = \dfrac{U_{IN}}{U_{IIN}}U_{B2}\) \(K_* = \dfrac{U_{It}/U_{B1}}{U_{IIt}/U_{B2}} \neq 1\)
按线路额定电压选择 \(U_{B1} = U_{N1};\ U_{B2} = U_{N2}\) \(K_* = \dfrac{U_{It}/U_{B1}}{U_{IIt}/U_{B2}} \neq 1\)
  • 工程上选取平均额定电压 U_AV 作为各级电压基准值
U_N (kV) 3 6 10 35 110 220 330 500
U_AV (kV) 3.15 6.3 10.5 37 115 230 345 525

系统：\(Z_1 = 4 + j60\ \Omega\) — 变压器 110/11 kV — \(Z_2 = 4 + j60\ \Omega\)

a) 选取线路额定电压为各级电压基准值，S_B = 20 MVA

\[\begin{cases} U_{B1} = 110\ \text{kV} \\ U_{B2} = 10\ \text{kV}\end{cases}\qquad \begin{cases} Z_{B1} = \dfrac{110^2}{20} = 605\ \Omega \\[6pt] Z_{B2} = \dfrac{10^2}{20} = 5\ \Omega\end{cases}\]

\[\begin{cases} Z_{1*} = \dfrac{4+j60}{605} = 0.0066 + j0.099 \\[6pt] Z_{2*} = \dfrac{4+j60}{5} = 0.8 + j12\end{cases}\qquad K_* = \frac{U_{It}/U_{B1}}{U_{IIt}/U_{B2}} \approx 0.91\]

等值电路：0.0066+j0.099 — [0.91:1] — 0.8+j12

Π型等值变换： \[Z_{ij*} = K_*Z_t = 0.91(0.8+j12) \approx 0.73 + j10.92\] \[\begin{cases} Z_{i0*} = \dfrac{K_*}{K_*-1}Z_t = \dfrac{0.91}{0.91-1}(0.8+j12) \approx -(8.09 + j121.33) \\[8pt] Z_{j0*} = \dfrac{K_*^2}{1-K_*}Z_t = \dfrac{0.91^2}{1-0.91}(0.8+j12) \approx 7.36 + j110.41 \end{cases}\]

P15　3、近似计算法

  • 选取线路平均额定电压 U_av 为各级电压基准值
  • 近似认为所有元件电压为平均额定电压

基准值：\(U_{B3} = 10.5\ \text{kV}\)，\(U_{B1} = 230\ \text{kV}\)，\(U_{B2} = 37\ \text{kV}\)

\[G:\quad X_{d*} = X_d\frac{S_B}{U_B^2} = X_{d*}(\text{铭牌})\times\frac{U_N^2}{S_N}\times\frac{S_B}{U_{av}^2} = X_{d*}(\text{铭牌})\times\frac{S_B}{S_N}\]

\[T:\quad R_{T*} = \frac{P_k}{1000S_N}\times\frac{U_N^2}{S_N}\times\frac{S_B}{U_B^2} = \frac{P_k}{1000S_N}\times\frac{U_{av}^2}{S_N}\times\frac{S_B}{U_{av}^2} = \frac{P_k}{1000S_N}\times\frac{S_B}{S_N}\]

\[X_{T*} = \frac{U_k\%}{100}\times\frac{U_N^2}{S_N}\times\frac{S_B}{U_B^2} = \frac{U_k\%}{100}\times\frac{U_{av}^2}{S_N}\times\frac{S_B}{U_{av}^2} = \frac{U_k\%}{100}\times\frac{S_B}{S_N}\]

\[K_* = \frac{U_{It*}}{U_{IIt*}} = \frac{U_{av1}/U_{av1}}{U_{av2}/U_{av2}} = 1\]

近似计算法的核心：\(U_N \approx U_{av}\)，于是 \(\left(\dfrac{U_N}{U_{av}}\right)^2 = 1\)，标幺变比恒为 1，可省去理想变压器。

P16　近似计算法算例（对应 P12/P13 同一系统）

选取平均额定电压为各级电压基准值，S_B = 20 MVA，近似计算法：

\[\begin{cases} U_{B1} = 115\ \text{kV} \\ U_{B2} = 10.5\ \text{kV}\end{cases}\qquad \begin{cases} Z_{B1} = \dfrac{115^2}{20} = 661.25\ \Omega \\[6pt] Z_{B2} = \dfrac{10.5^2}{20} = 5.513\ \Omega\end{cases}\]

\[\begin{cases} Z_{1*} = \dfrac{4+j60}{661.25} \approx 0.006 + j0.091 \\[6pt] Z_{2*} = \dfrac{4+j60}{5.513} \approx 0.726 + j10.883\end{cases}\qquad K_* = \frac{115/115}{10.5/10.5} = 1\]

等值电路：0.006+j0.091 — [1:1] — 0.726+j10.883，因变比为 1，理想变压器可直接去掉。

本章方法脉络小结

  1. 建模：发电机（E、X_d）+ 变压器（串联阻抗+理想变）+ 线路（串联阻抗/Π型）+ 负荷（恒功率/恒阻抗）→ 电力网络模型。
  2. 标幺制：选 S_B、U_B 两个基准 → \(I_B = S_B/(\sqrt3 U_B)\)、\(Z_B = U_B^2/S_B\)。
  3. 多电压等级处理的三条路线：
    • 逐级归算法：用变比 k 把参数归算到基本级（最高电压级）。
    • 各选电压法：各级各自选 U_B，保留标幺变比 K_*。
    • 近似计算法：各级 U_B 取平均额定电压 U_av，K_* ≡ 1，计算最简。
