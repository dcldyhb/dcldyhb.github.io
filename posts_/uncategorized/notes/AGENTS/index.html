Notes：多模型协作说明

Notes：多模型协作说明

本文件是本仓库的共用说明，供 ChatGPT / Codex、DeepSeek Harness（DSH）和 Claude 使用。长期规则统一在此维护；CLAUDE.md 仅作引用入口。 目录信息于 2026-11-07 核对，实际文件、最新用户指令和当前验证结果优先。

1. 任务理解与工作边界

  • 默认使用简体中文。执行非平凡任务前，必须完全理解用户目标；存在不确定、 冲突或多种解释时，先澄清，不能自行假设。
  • 这是课程笔记与个人学习资料库，包含 Markdown、图片、LaTeX 工程及编译产物。 根目录没有统一的软件构建或测试流程，按具体任务选择检查。
  • 只处理本次授权范围。梳理、盘点和生成说明不代表允许搬移、改名、删除原资料。
  • 保留用户已有修改和未跟踪文件，不执行覆盖性恢复或批量清理。 不因发现缺口表而自动开始补课、合并草稿或修正整库内容。
  • 不主动修改 .obsidian/、.vscode/ 或全局模型配置。 提交、推送、发布以及向外部服务传输文件，遵循用户明确授权。

2. 开工、恢复与模型切换

新会话、模型切换、上下文压缩或怀疑现场丢失后，先只读恢复，再开展非平凡任务：

  1. 确认当前工作目录；读取该目录适用的 AGENTS.md，包括仓库根目录与任务路径上的说明。
  2. 读取任务入口，以及它指定的 progress、handoff、goal 或验证记录。 已有任务交接文件时优先读取；没有时明确说明，不假装保留前一模型的聊天上下文。
  3. 检查当前文件树和 git status --short；必要时查看目标文件差异。 先区分已有修改、本轮修改、源资料和生成产物。
  4. 在修改、运行或最终汇报前，简要说明已恢复的目标、待办和关键风险。 如目标、现场或约定冲突，先停下汇报并澄清。

各工具如何使用本说明

  • ChatGPT / Codex：在支持本地仓库说明的环境中使用根目录大写 AGENTS.md。 普通聊天环境应主动提供本文件、任务交接及相关资料，不依赖自动读取本地文件。
  • DeepSeek Harness：从本仓库作为工作目录启动或选择本仓库工作区。 已安装版本的指令插件默认识别大写 AGENTS.md 和 CLAUDE.md； 不解释 Claude 的 @path 导入语法，因此共用正文必须保留在 AGENTS.md。 插件或配置变化后，以实际加载结果为准。
  • Claude Code：根目录 CLAUDE.md 用 @AGENTS.md 引用共用正文。 若所用客户端不支持导入，则显式读取 AGENTS.md。 普通 Claude 聊天环境同样需要手动提供文件与任务资料。
  • 不在多个模型专属文件中复制整份规则。工具缺失、无法访问文件或尚未运行检查时， 如实说明能力边界，不把另一会话的结果说成本轮实测。

4. 内容、Markdown 与公式规范

  • 优先保持原文件结构、表述风格、YAML front matter 和图片链接。 新建同类课程笔记时参考邻近文件的 title、category、tags、math、date。
  • 遵循标准 Markdown、LaTeX 和适用的 markdownlint 规则；无项目配置时用默认规则。 标题层级连续，列表和代码围栏前后留空行，代码围栏注明语言，文件末尾保留换行。 本次范围以外的旧格式问题不批量重排。
  • 普通聊天：行内公式使用 \(...\)，行间公式使用 \[...\]，公式块前后留空行。
  • 用户明确要求导出的 Markdown 内容：行内公式使用 $...$；行间公式使用 $$， 起止标记分别独占一行，公式块前后留空行。编辑已有文件时保留其现有数学定界风格， 不为统一符号而重写全文；与本次要求冲突时先澄清。
  • 单位和说明性下标适当用 \mathrm{}；普通变量不一律改正体。 微分用 \mathrm{d}，积分中在微分元前用 \,。中文结论优先写在公式外。
  • 定义、公式和数值应保留原课件页码、符号、单位与适用条件；注明 PDF 页码、 幻灯片页码和印刷页码的区别。补充推导、读图解释和个人判断须与原文区分。
  • 提取文本和 OCR 只作辅助；公式、上下标、表格、图示方向有疑义时回原页核对。 未核实的疑似错误保留不确定标记，不凭常识补造缺失页、公式或课程要求。
  • 保留相对路径、Obsidian 链接和现有远程图床链接的含义；改名或移动前检查引用。 新图片优先放在所属笔记的 .assets/ 或所属工程的 figures/，避免散落根目录。

6. Gemini 多模态识别

  • 主模型以用户当前选择为准；Gemini 作为图片、音频、视频处理工具。 默认先检查 gemini_status，配置正常不代表登录有效或识别成功。
  • 手写、文字和数学公式用 gemini_recognize_handwriting；普通识图用 gemini_analyze_file；视频用 gemini_analyze_video； 音频用 gemini_transcribe_audio。
  • 使用工具允许目录中的绝对路径。上传前确认具体文件将发送至 Google Gemini， 获得授权后才设置 upload_confirmed=true；同一文件与目标服务的既有明确授权可沿用。
  • 已授权聊天附件优先取得原文件；若不在允许目录或返回 path_not_allowed， 仅将该附件复制到 /Users/fangyan/Projects/gemini-codex-mcp/local_samples/， 用唯一文件名保留原件，再以副本路径重试。副本沿用同一附件的上传授权。 无法取得或复制时说明原因，不能声称已上传。
  • 工具缺失、登录失败、网络失败、超时或无法识别时，明确说明原因； 图片任务改用当前主模型实际具备的识图能力，并注明由哪个模型识别。 使用 ChatGPT 时由 GPT 回退识图；当前主模型不能读图时如实说明，不能编造。 音频、视频能力以工具说明和实测为准。
