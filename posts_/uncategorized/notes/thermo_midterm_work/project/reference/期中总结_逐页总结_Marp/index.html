第 2 页｜能源形式与科学用能：章节导入

本章围绕三个问题展开：

  1. 能源有哪些形式？ 区分资源类型及其利用方式。
  2. 能量怎样转换？ 认识锅炉、汽轮机、燃气轮机和内燃机。
  3. 怎样提高用能效果？ 关注转换效率、温度匹配与梯级利用。

复习主线：能源资源 → 转换设备 → 能量转换链 → 科学用能。

第 3 页｜能源类型及利用方式

分类或对象 课件列举的内容 复习要点
不可再生能源 煤炭、石油、天然气 也是课件列举的常规能源
新能源相关形式 风能、太阳能、生物质、氢能 区分资源与能量载体
其他利用形式 水能、核能、储能 分类维度并不完全相同
  • 可再生性与常规／新能源是不同的分类依据。
  • 阅读提示：氢主要是能量载体；其可再生属性取决于制氢来源。
  • 储能是能量存储与调节方式，不能与一次能源资源直接等同。

第 4 页｜能源转换设备的分工

设备 主要能量转换 在系统中的作用
锅炉 燃料化学能 → 工质热能 产生满足参数要求的蒸汽
汽轮机 蒸汽热能 → 机械能 驱动发电机或其他机械
燃气轮机 燃料能量 → 燃气能量 → 机械能 压气、燃烧、膨胀连续进行
内燃机 缸内燃烧放热 → 机械能 常以活塞往复运动输出功

阅读提示：设备输出的机械能还需经发电机转换为电能。

第 5 页｜火力发电厂的蒸汽动力循环

  • 燃料侧：煤炭制备、输送和燃烧，为锅炉提供热量。
  • 汽水侧：给水 → 锅炉加热、汽化、过热 → 汽轮机膨胀做功。
  • 冷端：汽轮机排汽 → 凝汽器 → 凝结水及给水系统 → 锅炉。
  • 电力侧：汽轮机驱动发电机，电能经电气设备送出。
  • 风烟侧：空气助燃，烟气放热后经净化装置排出。

读图时先找汽水闭合回路，再辨认燃料、空气、烟气和冷却水的流向。

第 6 页｜串联能量转换效率

课件示例：锅炉环节约 \(92\%\)，汽轮机环节约 \(42\%\)， 发电机环节约 \(98\%\)。

\[ \eta_{\mathrm{tot}} =\eta_{\mathrm{b}}\eta_{\mathrm{ST}}\eta_{\mathrm{g}} =0.92\times0.42\times0.98 \approx0.379\approx38\% \]

  • 下标 \(\mathrm{b}\)、\(\mathrm{ST}\)、\(\mathrm{g}\) 分别指锅炉、汽轮机、发电机。
  • 各环节的输出作为下一环节的输入时，总效率等于效率之积。
  • 课件示例中，热能转机械能环节的转换比例最低。
  • 这些数值用于说明转换链，不代表所有机组的固定效率。

第 7 页｜科学用能与梯级利用

核心原则：分配得当、各取所需、温度对口、梯级利用。

  • 高品位能量优先满足发电、动力等需求，再利用剩余热量。
  • 课件示意：燃气轮机／内燃机余热 → 吸收式制冷 → 低温热利用。
  • 图示中温余热约为 \(300\sim500\,\mathrm{^{\circ}C}\)， 低温余热约为 \(100\sim200\,\mathrm{^{\circ}C}\)。
  • 较低温度热源可服务供热、热泵及热驱动除湿等用途。
  • AI 用能优化：结合系统输入、输出与运行数据，协调设备及能源分配。

第 8 页｜锅炉：章节导入

锅炉部分的复习顺序：

  1. 作用与分类：产生什么蒸汽，如何组织工质流动。
  2. 结构与系统：区分本体、辅助设备、燃料、风烟和汽水流程。
  3. 热平衡：输入热量如何分配，效率如何计算，损失怎样降低。

主线：燃料燃烧放热 → 受热面传热 → 工质吸热形成蒸汽。

第 9 页｜锅炉的作用与蒸汽参数

锅炉完成循环工质的加热、汽化和蒸汽过热。

  • 能量转换：燃料化学能 → 热能 → 工质焓的增加。
  • 蒸汽的“质”：压力 \(p\)、温度 \(t\)、纯净度。
  • 蒸汽的“量”：蒸发量 \(D\)，表示单位时间内产生的蒸汽量。
  • 相互耦合的三个过程：燃料燃烧、工质吸热、烟气放热。
  • 锅炉除生产主蒸汽外，还可承担汽轮机排汽的再热任务。

复习时应同时关注蒸汽参数和流量，不能只比较温度。

第 10 页｜锅炉的两类分类依据

分类依据 主要类型
水循环方式 自然循环、强制循环、直流
出口蒸汽参数 低压、中压、高压、超高压、亚临界、超临界、超超临界
  • 循环方式说明水／汽在受热面中如何流动。
  • 蒸汽参数说明出口蒸汽的压力、温度等级。
  • 两种分类彼此关联，但描述的是不同特征。
  • 后续重点：有无汽包、循环驱动力以及是否一次通过受热面。

第 11 页｜“炉”与“锅”的结构分工

  • 炉侧：燃料在炉膛中燃烧，化学能转变为高温烟气的热能。
  • 锅侧：工质经预热、蒸发和过热三个阶段吸热。
  • 省煤器：未饱和水 → 接近或达到饱和状态的水。
  • 水冷壁等蒸发受热面：水受热形成汽水混合物；汽包承担分离等作用。
  • 过热器：饱和蒸汽 → 过热蒸汽。
  • 烟气沿各受热面放热；空气预热、引风及烟气净化设备辅助运行。

阅读提示：汽包是分离、汇集及循环组织部件，不宜等同于蒸发受热面。

第 12 页｜锅炉本体的主要部件

部件 主要作用
炉膛、燃烧器、炉墙 组织燃烧、形成燃烧空间并保温
汽包 汽水分离，连接循环回路
水冷壁 吸收炉膛热量，使水蒸发
过热器、再热器 分别加热主蒸汽、汽轮机高压缸排汽
省煤器 利用烟气余热预热给水
空气预热器 利用烟气余热加热助燃空气

记忆线索：燃烧空间 + 汽水受热面 + 尾部余热利用设备。

第 13 页｜锅炉辅助设备

课件列出八类辅助设备或功能：

  1. 燃料供应、磨煤机：完成燃料供给和煤粉制备。
  2. 送风、引风：提供空气并维持烟气流动。
  3. 给水：向锅炉输送满足要求的水。
  4. 除灰除渣：排出飞灰、底渣等固体产物。
  5. 脱硫脱硝：控制烟气污染物。
  6. 自动控制：协调燃烧、汽水参数和设备运行。

区分：本体直接组织燃烧与传热，辅助设备保证本体连续、稳定运行。

第 15 页｜自然循环、强制循环与直流锅炉

类型 汽包 工质流动的主要驱动力 流动特点
自然循环 有 下降管与上升管内工质的密度差 回路内循环
强制循环 有 密度差及循环泵压头 泵辅助循环
直流 无 给水泵压头 一次通过各受热面
  • 自然循环的关键是建立可靠的密度差循环压头。
  • 强制循环在循环回路中增设循环泵。
  • 直流锅炉不依赖汽包组织循环，给水持续流过加热、蒸发和过热区段。

第 16 页｜锅炉系统总览

课件将锅炉系统分为四部分：

  • 煤粉制备：煤仓、给煤机、磨煤机及送粉设备。
  • 燃烧系统：燃烧器、炉膛、水冷壁及排渣装置。
  • 风烟系统：送风机、空气预热器、烟道、净化设备、引风机及烟囱。
  • 汽水系统：给水、汽包、下降管、水冷壁、过热器和再热器。

读总图的方法：先按介质分线，再沿流向找设备；避免只背部件编号。

第 17 页｜煤粉制备和燃烧流程

燃料主线：

煤仓（原煤） → 给煤机 → 磨煤机（煤粉） → 燃烧器 → 炉膛。

热空气支线：

送风机（冷空气） → 空气预热器 → 热空气 → 磨煤及送粉环节。

  • 热空气用于加热、干燥和输送煤粉。
  • 煤粉与空气进入炉膛燃烧，产生高温烟气。
  • 底部灰渣经排渣装置排出；烟气继续进入后续受热面和烟道。

第 18 页｜风烟系统与余热回收

课件流程：烟气 → 过热器 → 再热器 → 省煤器 → 空气预热器 → 除尘器 → 引风机 → 脱硫脱硝装置 → 烟囱。

课件中的亚临界 \(600\,\mathrm{MW}\) 机组示例 温度
进口烟温／排烟温度 \(1000/128\,\mathrm{^{\circ}C}\)
过热蒸汽出口／省煤器出口水温 \(541/310\,\mathrm{^{\circ}C}\)
一次风／二次风温度 \(284/307\,\mathrm{^{\circ}C}\)
  • 烟气逐级放热，分别服务蒸汽、给水和空气加热。
  • 阅读提示：净化设备的实际布置因机组而异，此处按课件示意记忆。

第 19 页｜煤粉与风烟系统的耦合

  • 一次风：参与煤粉干燥和输送，将煤粉送至燃烧器。
  • 二次风：向燃烧区域补充空气，满足燃烧所需氧气。
  • 煤粉燃烧后，烟气流经炉膛、水平烟道与尾部烟道并放热。
  • 烟气中的飞灰由除尘装置分离，炉底灰渣由冷灰斗及排渣装置排出。
  • 未燃煤粒随飞灰、灰渣排出，会形成固体不完全燃烧热损失。

本页三个功能：干燥输粉、供氧燃烧、向工质传热。

第 20 页｜汽水系统的状态变化

主蒸汽流程：

给水 → 省煤器 → 饱和水 → 水冷壁蒸发 → 饱和蒸汽 → 过热器 → 过热蒸汽 → 汽轮机高压缸。

再热流程：

高压缸排汽 → 再热器 → 再热蒸汽 → 后续汽轮机缸体。

  • 省煤器主要承担预热，水冷壁主要承担蒸发，过热器承担过热。
  • 过热器与再热器的入口工质来源不同，不可混淆。
  • 本图按亚临界汽包锅炉的典型状态变化理解。

第 21 页｜汽包锅炉的汽水循环

  • 给水进入：主凝结水及化学补充水 → 给水泵 → 省煤器 → 汽包。
  • 循环回路：汽包 → 下降管 → 下联箱 → 水冷壁 → 上联箱 → 导汽管 → 汽包／汽水分离环节。
  • 蒸汽送出：分离出的饱和蒸汽 → 过热器 → 汽轮机调节级。
  • 下降管内主要为水；水冷壁出口及导汽管内为汽水混合物。
  • 汽水分离使蒸汽与回路中的循环水分开，后者继续参与循环。

读图重点：区分外部给水、内部循环水、送出蒸汽三条关系。

第 23 页｜锅炉热平衡的六项输出

\[ Q_{\mathrm{f}}=Q_1+Q_2+Q_3+Q_4+Q_5+Q_6 \]

项目 含义
\(Q_1\) 向工质传递的有效利用热量
\(Q_2\) 排烟及其携带飞灰带走的热量
\(Q_3\) 未燃尽可燃气体带走的热量
\(Q_4\) 飞灰、灰渣中未燃尽可燃物带走的热量
\(Q_5\) 炉墙向环境散热
\(Q_6\) 其他损失，课件后页重点讨论灰渣物理热

\(Q_{\mathrm{f}}\) 为输入热量；热效率为 \(Q_1/Q_{\mathrm{f}}\)。

第 24 页｜正平衡、反平衡与热损失

统一采用小数形式：\(q_j=Q_j/Q_{\mathrm{f}}\)。

\[ \eta_{\mathrm{b}}=q_1 =1-(q_2+q_3+q_4+q_5+q_6) \]

  • 正平衡测有效利用热；反平衡测各项损失。写百分数时整体乘 \(100\%\)。
  • \(q_2\) 与排烟温度、烟气量有关；课件估计温度升高 \(10\sim15\,\mathrm{^{\circ}C}\)，损失约增加 1 个百分点。
  • 煤粉锅炉示例：\(q_3\approx0\)，\(q_4\approx0.5\%\sim1\%\)。
  • 负荷提高时 \(q_5\) 的比例通常减小；课件列 \(D>900\,\mathrm{t/h}\) 时 \(q_5\approx0.2\%\)。\(q_6\) 与灰渣温度、含灰量有关。

阅读提示：课件末条忽略 \(q_6\) 的判据缺少单位说明，计算前需核实。

第 25 页｜汽轮机：章节导入

本章沿“蒸汽如何做功”展开：

  1. 定义与分类：认识蒸汽动力机械。
  2. 基本级：静叶、动叶、速度三角形及热力过程。
  3. 级的性能：反动度、各种损失、相对内效率。
  4. 多级汽轮机：分级膨胀与高、中、低压缸。
  5. 凝汽系统：维持排汽低压并回收凝结水。

第 26 页｜汽轮机定义及能量转换链

汽轮机利用蒸汽能量驱动叶轮旋转，输出机械功。

火电厂能量转换：

燃料化学能 → 锅炉 → 蒸汽热能 → 汽轮机 → 机械能 → 发电机 → 电能。

  • 蒸汽也可以来自其他蒸汽发生装置。
  • 汽轮机可驱动发电机，也可驱动其他机械。
  • 课件列举用途：火电、核电、舰船和工业驱动。

区分：锅炉负责向工质输入热量，汽轮机负责从蒸汽中取得机械功。

第 27 页｜汽轮机的分类

分类依据 主要类型
工作原理 冲动式、反动式
蒸汽流动方向 轴流式、径流式、混流式
主蒸汽参数 低压、中压、高压、超高压、亚临界、超临界、超超临界
  • 冲动／反动关注蒸汽在静叶和动叶中的膨胀分配。
  • 轴流／径流／混流关注蒸汽的整体流动方向。
  • 主蒸汽参数等级与前述锅炉参数共同构成机组的热力条件。

第 28 页｜汽轮机的基本做功单元：级

  • 一个级由一列喷嘴叶栅与配合工作的动叶栅组成。
  • 动叶栅可为单列，也可采用多列，例如双列复速级。
  • 相邻静叶形成喷嘴通道；相邻动叶形成动叶通道。
  • 喷嘴使蒸汽膨胀加速：热能 → 汽流动能。
  • 动叶使汽流与叶轮交换动量：汽流能量 → 转子机械能。

阅读提示：这是能量转换的基本描述；在反动级中，蒸汽还在动叶内膨胀。

第 29 页｜速度三角形与参考系

\[ \boldsymbol{c}=\boldsymbol{u}+\boldsymbol{w} \]

  • \(\boldsymbol{c}\)：汽流相对静止坐标系的绝对速度。
  • \(\boldsymbol{u}\)：动叶的圆周速度。
  • \(\boldsymbol{w}\)：汽流相对运动叶片的相对速度。
  • 下标 \(1\)、\(2\) 分别表示动叶入口、出口。
  • 课件示意 \(c_1>c_2\)，说明汽流绝对动能的一部分转换为机械能。

速度三角形用于连接流动方向、叶片运动和做功；不能把 \(c\) 与 \(w\) 混用。

第 30 页｜级内速度变化与轮周功

状态顺序：喷嘴前 \(0\) → 动叶入口 \(1\) → 动叶出口 \(2\)。

在课件采用的绝热、忽略位能变化的级模型下：

\[ W_{\mathrm{u}} =\left(h_0+\frac{c_0^2}{2}\right) -\left(h_2+\frac{c_2^2}{2}\right) \]

  • \(W_{\mathrm{u}}\) 是单位质量蒸汽对应的轮周比功。
  • 焓与速度动能必须使用一致单位：\(c^2/2\) 按 \(\mathrm{J/kg}\) 计； 换成 \(\mathrm{kJ/kg}\) 时应除以 \(1000\)。
  • 阅读提示：功率还需乘质量流量；课件“单位时间内所做的功”表述需区分。

第 31 页｜级的焓降及损失符号

\[ \begin{aligned} \Delta h_{c0}&=\frac{c_0^2}{2}, &\Delta h_{c2}&=\frac{c_2^2}{2}\\ \Delta h_{\mathrm{n}}&=h_0-h_{1\mathrm{t}}, &\Delta h_{\mathrm{n}\xi}&=h_1-h_{1\mathrm{t}}\\ \Delta h_{\mathrm{b}}&=h_1-h_{2\mathrm{t}}, &\Delta h_{\mathrm{b}\xi}&=h_2-h_{2\mathrm{t}}\\ \Delta h_{\mathrm{t}}&=h_0-h_{2\mathrm{t}}', &\Delta h_{\mathrm{t}}^*&=\Delta h_{\mathrm{t}}+\Delta h_{c0} \end{aligned} \]

  • \(\mathrm{n}\)、\(\mathrm{b}\) 分别表示喷嘴、动叶；\(\xi\) 表示相应损失。
  • \(1\mathrm{t}\)、\(2\mathrm{t}\) 是分段等熵出口；\(2\mathrm{t}'\) 是整级等熵出口。
  • 课件近似：\(\Delta h_{\mathrm{t}}\approx \Delta h_{\mathrm{n}}+\Delta h_{\mathrm{b}}\)；星号表示计入入口动能。

第 32 页｜反动度的定义

反动度衡量蒸汽在动叶通道内的膨胀程度。

\[ \Omega_{\mathrm{m}} =\frac{\Delta h_{\mathrm{b}}}{\Delta h_{\mathrm{t}}^*} \approx \frac{\Delta h_{\mathrm{b}}} {\Delta h_{\mathrm{n}}^*+\Delta h_{\mathrm{b}}} \]

  • 分子：动叶内的理想比焓降。
  • 分母：级的滞止理想比焓降。
  • \(\Delta h_{\mathrm{n}}^*\) 表示把入口动能计入的喷嘴理想能量。
  • 反动度越大，动叶内承担的膨胀份额越大。

阅读提示：它是焓降的分配比例，不是动叶输出功占整级输出功的比例。

第 33 页｜冲动原理与反动原理

原理 物理图像 在叶片中的体现
冲动 流体速度大小或方向改变，产生作用力 汽流转向并向动叶传递动量
反动 流体在运动部件通道内膨胀加速，产生反作用 动叶内膨胀与加速参与做功
  • 冲动原理强调汽流动量改变对叶片产生的力。
  • 反动原理强调动叶通道内膨胀加速产生的反作用。
  • 实际汽轮机中两种作用可同时存在。

判断级型时，应结合动叶压降和反动度。

第 34 页｜纯冲动级与反动级

比较项 纯冲动级 课件中的典型反动级
反动度 \(\Omega_{\mathrm{m}}=0\) \(\Omega_{\mathrm{m}}=0.5\)
膨胀位置 主要在喷嘴 喷嘴与动叶中均有膨胀
动叶内理想过程 不膨胀，主要改变汽流方向 膨胀并参与加速
课件叶型描述 静、动叶承担不同任务 喷嘴与动叶叶型相同
课件性能比较 做功能力较大，损失较大 做功能力较小，效率较高

阅读提示：表中性能是课件在相应设计条件下的比较，不能脱离条件泛化。

第 35 页｜带反动度的冲动级

课件给出的典型范围：

\[ \Omega_{\mathrm{m}}=0.05\sim0.3 \]

  • 以冲动作用为主，同时保留一定反动作用。
  • 动叶中有一定膨胀，入口压力高于出口压力。
  • 在课件比较的最佳速比条件下，做功能力比反动级大。
  • 效率比纯冲动级高，是工程中广泛采用的形式。

记忆：冲动级不一定是纯冲动级；只有纯冲动级的反动度为零。

第 36 页｜级的理想能量与余速利用

\[ E_0=\frac{c_0^2}{2}+\Delta h_{\mathrm{t}} -\mu_1\frac{c_2^2}{2} =\Delta h_{\mathrm{t}}^*-\mu_1\Delta h_{c2} \]

  • \(\mu_1\) 为余速利用系数，表示本级出口动能被下一级利用的份额。
  • 课件取值：排汽级为 \(0\)，抽汽级约 \(0\sim0.5\)，中间级为 \(1\)。
  • \(E_0\) 从理想滞止焓降中扣除了归给下一级利用的出口动能。
  • 设计关注：合理降低动叶出口绝对速度 \(c_2\)，改善余速利用。

本页原课件标题编号写作“2.2”，内容仍属于汽轮机级的效率分析。

第 37 页｜级的相对内效率

\[ \eta_{\mathrm{i}} =\frac{\Delta h_{\mathrm{i}}}{E_0} =\frac{\Delta h_{\mathrm{i}}} {\Delta h_{\mathrm{t}}^*-\mu_1\Delta h_{c2}} \]

\[ \Delta h_{\mathrm{i}} =\Delta h_{\mathrm{t}}^* -\Delta h_{\mathrm{n}\xi} -\Delta h_{\mathrm{b}\xi} -\Delta h_{c2}-\sum\Delta h \]

  • 分子 \(\Delta h_{\mathrm{i}}\)：扣除各项损失后的有效比焓降。
  • \(\sum\Delta h\) 表示课件未逐项展开的其他级内损失。
  • 余速利用既影响损失评价，也影响理想能量的计量边界。
  • 复习时将本页与前页的 \(E_0\)、\(\mu_1\) 定义配套使用。

第 38 页｜汽轮机级的练习结论

  1. 推动叶轮旋转做功的是周向力，原题选 C。 周向力形成绕主轴的转矩。
  2. 带反动度 \(0.05\sim0.3\) 的冲动级，动叶内存在膨胀， 因而 \(p_1>p_2\)，原题选 A。
  3. 反动度为 \(0.5\) 时，喷嘴理想滞止焓降与动叶理想焓降相等， 原题选 C。

\[ \Omega_{\mathrm{m}}\approx \frac{\Delta h_{\mathrm{b}}} {\Delta h_{\mathrm{n}}^*+\Delta h_{\mathrm{b}}}=0.5 \quad\Rightarrow\quad \Delta h_{\mathrm{n}}^*=\Delta h_{\mathrm{b}} \]

第 39 页｜多级汽轮机为何效率较高

  • 总焓降分配给多个级，每级焓降减小，更容易在较小直径下匹配最佳速比。
  • 上一级出口的余速动能，可以在下一级继续利用。
  • 课件指出汽流多处于亚音速流动，有利于减小流动损失。
  • 在所需通流面积一定时，减小级平均直径可以增加叶高。

\[ A\approx\pi d l \]

其中 \(d\) 为平均直径，\(l\) 为叶高。上述因素共同提高相对内效率。

第 40 页｜高、中、低压缸的特征

比较项 高压缸 中压缸 低压缸
蒸汽状态 高温、高压 高温、中压 低温、低压
容积流量／平均直径 小／小 中／中 大／大
课件中的级焓降、反动度 较小 中等 较大
主要损失 叶高、漏汽、部分进汽 漏汽 湿汽
课件中的效率比较 较低 较高 稍低
  • 蒸汽膨胀后比容增大，后部通常需要更大的通流面积。
  • 课件给出的典型效率排序：中压缸 > 低压缸 > 高压缸。

第 41 页｜汽轮机与发电机的效率边界

\[ \eta_{\mathrm{m}}=\frac{P_{\mathrm{e}}}{P_{\mathrm{i}}}, \qquad \eta_{\mathrm{g}}=\frac{P_{\mathrm{el}}}{P_{\mathrm{e}}} \]

\[ \eta_{\mathrm{i}} =\frac{\Delta h_{\mathrm{i}}^{\mathrm{mac}}} {\Delta h_{\mathrm{t}}^{\mathrm{mac}}} \]

  • \(P_{\mathrm{i}}\)：汽轮机内功率；\(P_{\mathrm{e}}\)：联轴器端输出的轴功率。
  • \(P_{\mathrm{el}}\)：发电机电功率；\(\mathrm{mac}\) 表示整机。
  • 机械效率反映轴承摩擦、主油泵等机械耗功。
  • 相对内效率评价通流部分，机械效率评价传动损耗，发电机效率评价机电转换。

第 42 页｜凝汽系统与不凝结气体

凝汽系统主要由凝汽器、循环水泵、凝结水泵、抽气器组成。

  • 凝汽器：将汽轮机排汽凝结，形成低排汽压力并回收凝结水。
  • 循环水泵：使冷却水循环，带走凝结放热。
  • 凝结水泵：将凝结水送往后续汽水系统。
  • 抽气器：排除空气等不凝结气体。
  • 不凝结气体积聚 → 总压力升高、局部换热恶化 → 凝汽器压力上升、真空度下降。

关键关系：真空变差意味着排汽绝对压力升高。

第 43 页｜最佳真空、极限真空与有效真空

  • 冷却水流量增加，通常使凝汽器压力下降，汽轮机出力增加。
  • 同时循环水泵耗功增加，需比较新增出力和新增耗功。

\[ P_{\mathrm{net}}(D_{\mathrm{c}}) =N_{\mathrm{el}}(D_{\mathrm{c}}) -P_{\mathrm{pump}}(D_{\mathrm{c}}) \]

  • 最佳／经济真空：使上述净收益最大的运行点。
  • 极限真空：课件以冷却水进口温度对应的蒸汽饱和压力表示其极限。
  • 最大有效真空：末级动叶达到极限膨胀时的真空。

阅读提示：经济最优并不要求真空无限提高；两种“极限”也有不同含义。

第 44 页｜表面式与混合式凝汽器

类型 蒸汽与冷却介质的关系 主要特征
表面式 由换热壁面隔开 蒸汽凝结水与冷却水不直接混合
混合式 直接接触、混合换热 凝结水与冷却介质混合后排出
  • 表面式图中可辨认冷却管、前后水室、蒸汽入口和凝结水汇集空间。
  • 混合式图中冷却水经喷嘴进入，与排汽直接接触。
  • 区分依据是是否直接接触混合，不是有无凝结过程。

第 45 页｜表面式凝汽器的流程数

  • 课件指出：火电机组基本采用表面式凝汽器。
  • 按冷却水的流动方式，分为单流程和多流程。
  • 单流程：冷却水沿管束通过一次。
  • 多流程：借助水室分隔和转向，使冷却水分段通过管束。
  • 原图右侧以两段反向水流展示双流程形式。

阅读提示：“流程数”描述冷却水通过管束的路径，不是汽轮机的级数。

第 46 页｜水冷与空冷的比较

比较项 水冷 空冷
排汽压力／真空 较低／较高 较高／较低
投资 课件比较中较小 课件比较中较大
耗水 较大 较小
适用条件 水源条件较好 富煤缺水地区
  • 课件列举空冷适用地区：山西、内蒙古等。
  • 课件节水示例：冷却系统节水超过 \(97\%\)，全厂节水约 \(65\%\)。
  • 阅读提示：节水率是课件示例，取决于比较基准和系统边界。

第 47 页｜燃气轮机：章节导入

本章将部件作用与布雷顿循环联系起来：

  1. 压气机：消耗机械功，提高空气压力。
  2. 燃烧室：燃料与高压空气混合燃烧，提高工质温度。
  3. 涡轮：燃气膨胀做功，驱动压气机并输出剩余功。
  4. 循环性能：比功、热效率、增压比、温比和不可逆损失。

复习重点：涡轮输出功与机组净输出功有不同边界。

第 48 页｜燃气轮机的定义与组成

燃气轮机是以连续流动气体为工质的旋转叶轮式热力发动机。

  • 主要组成：压气机、燃烧室、涡轮／透平，以及辅助设备。
  • 空气经压气机升压后进入燃烧室，与燃料混合燃烧。
  • 高温燃气在涡轮中膨胀，将工质能量转变为机械功。
  • 涡轮功的一部分用于驱动压气机，其余用于外部负载。

\[ w_{\mathrm{net}}=w_{\mathrm{T}}-w_{\mathrm{C}} \]

此式对应简化模型；\(\mathrm{T}\)、\(\mathrm{C}\) 分别表示涡轮和压气机。

第 49 页｜压气机的作用

  • 旋转叶片连续对气体做功，使空气总压逐渐升高。
  • 压气机向燃烧室提供所需的高压空气。
  • 课件以轴流式压气机照片展示动、静叶排的组合。
  • 本页增压方式的判断：采用做功增压、连续做功。
  • 与往复式压缩装置相比，其工质流动与叶轮做功连续进行。

注意：压气机是机组内部的重要耗功部件，涡轮必须先满足其功率需求。

第 50 页｜燃烧室的作用与可靠性

燃烧室使压气机送来的高压空气与燃料混合、燃烧，向涡轮提供高温燃气。

问题 可能后果
燃烧不稳定 熄火
出口局部温度过高 透平叶片过热甚至烧毁
燃烧组织不良 流动损失增加、燃烧效率降低、积炭
  • 燃烧室需要兼顾稳定燃烧、温度分布和较小压力损失。
  • 阅读提示：高压主要由压气机建立；实际燃烧室中存在压力损失。

第 51 页｜三种燃烧室结构

类型 读图识别要点
分管型 多个独立管形燃烧单元沿周向布置
环管型 多个火焰筒布置在共同的环形机匣内
环型 整体呈连续环形的燃烧空间
  • 三者都承担燃料喷入、混合、稳定燃烧和向涡轮供气的任务。
  • 本页重点是名称与结构形式对应。
  • 不应仅凭本页图片推断三种结构的绝对优劣或固定适用功率。

第 52 页｜燃气透平的类型与特点

燃气透平将高温、高压燃气中的能量转换为机械功。

  • 轴流式：课件概括为功率大、流量大、效率高。
  • 径流式：主要用于小功率燃气轮机。
  • 工质温度高，对材料、冷却和可靠性提出要求。
  • 级焓降较高，单级能量转换较大。
  • 级的气动负荷大，因此整个透平通常采用较少的级数。

复习时将“高温、高级负荷、较少级数”联系起来记忆。

第 53 页｜涡轮与压气机对比

比较项 涡轮 压气机
能量方向 工质能量 → 机械能 机械能 → 工质能量
课件典型通道 收敛式 扩散式
典型流动 膨胀加速 扩压减速
级的构成顺序 静叶 + 动叶 动叶 + 静叶
叶型 厚、弯度大 薄、弯度小
温度／级数 高／少 相对低／多

阅读提示：表中是课件的典型比较；压气机总压上升由动叶输入功实现， 不能将“扩压减速”理解为所有叶排内的全部速度分量都减小。

第 54 页｜燃气轮机的比功与热效率

\[ W_{\mathrm{n}}=\frac{P}{q_{\mathrm{ma}}}, \qquad \eta_{\mathrm{s}}=\frac{P}{q_{\mathrm{mf}}H_{\mathrm{u}}} \]

  • \(P\)：机组净输出功率，单位 \(\mathrm{kW}\)。
  • \(q_{\mathrm{ma}}\)：空气质量流量，单位 \(\mathrm{kg/s}\)。
  • \(W_{\mathrm{n}}\)：按空气流量计的比功，单位 \(\mathrm{kJ/kg}\)。
  • \(q_{\mathrm{mf}}\)：燃料质量流量，单位 \(\mathrm{kg/s}\)。
  • \(H_{\mathrm{u}}\)：燃料低位发热量，单位 \(\mathrm{kJ/kg}\)。

比功反映单位空气流量的输出能力；热效率反映燃料输入的利用程度。

第 55 页｜理想布雷顿循环的四个过程

过程 理想过程 对应设备或物理过程
\(1\to2\) 等熵压缩 压气机耗功
\(2\to3\) 定压吸热 用吸热过程理想化燃烧室
\(3\to4\) 等熵膨胀 涡轮输出功
\(4\to1\) 定压放热 用放热过程闭合理想循环
  • 正向循环将输入热量的一部分转变为净机械功。
  • 图示中涡轮输出的大部分要返回压气机，只有剩余部分对外输出。
  • 阅读提示：实际开式机组吸入新空气并排出燃气；闭合回路是理想循环模型。

第 56 页｜由温差计算理想循环效率

采用定比热理想气体模型；\(T_j^*\) 表示各状态点的总温，使用 \(\mathrm{K}\)。

\[ \begin{aligned} q_{\mathrm{in}}&=c_p(T_3^*-T_2^*),\\ q_{\mathrm{out}}&=c_p(T_4^*-T_1^*),\\ w_{\mathrm{net}}&=q_{\mathrm{in}}-q_{\mathrm{out}} \end{aligned} \]

\[ \eta=\frac{w_{\mathrm{net}}}{q_{\mathrm{in}}} =1-\frac{T_4^*-T_1^*}{T_3^*-T_2^*} \]

阅读提示：统一用单位质量的热量、比功推导；若用功率，热输入也应改用热流率。

第 57 页｜增压比与理想热效率

令 \(\pi=p_2^*/p_1^*\)，\(\kappa=c_p/c_v\)。理想定压过程给出 \(p_2^*=p_3^*\)、\(p_4^*=p_1^*\)，结合等熵关系：

\[ \frac{T_2^*}{T_1^*} =\frac{T_3^*}{T_4^*} =\pi^{(\kappa-1)/\kappa} \quad\Rightarrow\quad \eta=1-\pi^{-(\kappa-1)/\kappa} \]

  • 在这些假设下，固定 \(\kappa\) 时，提高增压比可提高理想热效率。
  • 固定增压比而提高 \(T_3^*\)，净比功与吸热量增加，理想热效率不变。
  • 温比定义：\(\tau=T_3^*/T_1^*\)。

阅读提示：效率与温比无显式关系是理想模型结论，不能直接推广到实际循环。

第 58 页｜最大净比功对应的增压比

令 \(a=(\kappa-1)/\kappa\)，\(\tau=T_3^*/T_1^*\)，则：

\[ w_{\mathrm{net}} =c_pT_1^*\left[\tau(1-\pi^{-a})-(\pi^a-1)\right] \]

固定 \(T_1^*\)、\(T_3^*\) 与 \(c_p\)，对增压比求极值：

\[ \frac{\partial w_{\mathrm{net}}}{\partial\pi}=0 \quad\Rightarrow\quad \pi_{\mathrm{opt}}=\tau^{\kappa/[2(\kappa-1)]} \]

  • 温比越高，最大净比功对应的增压比越高；该最优点上的理想效率也提高。
  • 最大比功点与最高效率的追求不同；增压比过高会使净比功下降。
  • 阅读提示：课件此处用 \(P_{\mathrm{gt}}\) 表示的式子量纲为比功，已统一写作 \(w\)。

第 59 页｜实际循环与绝热效率

实际过程：\(1\to2\mathrm{a}\) 为不可逆绝热压缩， \(3\to4\mathrm{a}\) 为不可逆绝热膨胀；吸热与放热过程还伴随压力损失。

\[ \eta_{\mathrm{C}} =\frac{h_{2\mathrm{s}}-h_1}{h_{2\mathrm{a}}-h_1}, \qquad \eta_{\mathrm{T}} =\frac{h_3-h_{4\mathrm{a}}}{h_3-h_{4\mathrm{s}}} \]

  • \(\mathrm{s}\) 为相同出口压力下的等熵参考状态，\(\mathrm{a}\) 为实际状态。
  • 压气机：实际耗功大于理想耗功，效率为理想耗功／实际耗功。
  • 涡轮：实际出功小于理想出功，效率为实际出功／理想出功。
  • 不可逆损失使压气机耗功增加、涡轮出功减少，降低净输出与循环效率。

第 60 页｜内燃机：章节导入

本章复习主线：

  1. 结构：机体、两大机构、五大系统。
  2. 几何术语：止点、行程、工作容积、排量、压缩比。
  3. 工作循环：喷油与点火、四冲程与二冲程。
  4. 性能参数：转矩、功率、热效率和燃油消耗率。

注意把几何量、循环过程和性能指标分开，再建立它们的联系。

第 61 页｜内燃机的定义与分类

内燃机使燃料在机器内部燃烧，并将释放的热能转变为机械功。 课件随后主要讨论活塞式内燃机。

分类依据 类型
点火方式 点燃式、压燃式
冲程数 二冲程、四冲程
燃料 汽油机、柴油机、煤气机等
  • 汽油机、柴油机是常见的活塞式内燃机。
  • 点火方式、冲程数和燃料类别是不同维度，不能相互替代。

第 62 页｜一个机体、两大机构、五大系统

  • 一个机体：为各部件安装、支承与工作提供基础。
  • 曲柄连杆机构：连接活塞与曲轴，将往复运动转变为转动。
  • 配气机构：控制进、排气过程。
  • 五大系统：燃料供给、点火、润滑、冷却、启动。
  • 结构图重点辨认：气门、凸轮轴、火花塞／喷油器、活塞、曲轴。

阅读提示：课件按通用框架列系统；柴油机依靠压燃，通常不设置汽油机式火花点火系统。

第 63 页｜上、下止点与活塞行程

  • 上止点：活塞顶距曲轴回转中心最远的位置。
  • 下止点：活塞顶距曲轴回转中心最近的位置。
  • 活塞在上、下止点瞬时速度为零。
  • 活塞行程 \(S\)：上、下止点之间的距离；曲柄半径为 \(R\)。

对于气缸中心线通过曲轴回转中心的机构：

\[ S=2R \]

曲轴旋转一周，活塞完成两个行程；两个行程不一定等于一个工作循环。

第 64 页｜工作容积、排量与燃烧室容积

名称 含义
气缸工作容积 活塞从上止点移至下止点扫过的容积
内燃机排量 所有气缸工作容积之和
燃烧室／压缩容积 活塞处于上止点时，活塞顶以上的剩余容积

记单缸工作容积为 \(V_{\mathrm{s}}\)、缸径为 \(D\)、缸数为 \(z\)，总排量为 \(V_{\mathrm{disp}}\)：

\[ V_{\mathrm{s}}=\frac{\pi D^2}{4}S, \qquad V_{\mathrm{disp}}=zV_{\mathrm{s}} \]

本页 \(D\) 表示缸径，与锅炉部分的蒸发量 \(D\) 不同；排量不包含燃烧室容积。

第 65 页｜气缸总容积与压缩比

以 \(V_{\mathrm{c}}\) 表示燃烧室容积，\(V_{\mathrm{a}}\) 表示下止点时的总容积：

\[ V_{\mathrm{a}}=V_{\mathrm{s}}+V_{\mathrm{c}} \]

\[ \varepsilon =\frac{V_{\mathrm{a}}}{V_{\mathrm{c}}} =1+\frac{V_{\mathrm{s}}}{V_{\mathrm{c}}} \]

  • 压缩比 \(\varepsilon\) 是无量纲几何参数。
  • 其他条件相同时，压缩比增大意味着压缩终了压力、温度更高。
  • 压缩比是容积比，不能直接当作压缩前后压力之比。

第 66 页｜喷油与点火时序

三类机型均按“进气 → 压缩 → 做功 → 排气”组织四冲程循环。

机型 课件时序图的主要区别
气道喷射汽油机 燃油先在气道供给，混合气进入气缸，再由火花点火
缸内直喷汽油机 燃油直接喷入气缸，图示安排在压缩阶段，仍需火花点火
柴油机 先压缩空气，压缩末期喷油，依靠高温空气压燃
  • 区分两个问题：燃油在哪里喷入、混合气如何着火。
  • 图示为简化时序；实际喷油、点火位置会随设计和工况变化。

第 67 页｜四冲程工作循环

冲程 活塞运动 主要过程
进气 上止点 → 下止点 进气门开启，吸入新鲜充量
压缩 下止点 → 上止点 进排气门基本关闭，压缩气体
做功 上止点 → 下止点 燃烧后气体膨胀，推动活塞
排气 下止点 → 上止点 排气门开启，排出废气
  • 一个循环需要曲轴旋转两周，即 \(720^\circ\)。
  • 每缸每循环有一次做功冲程，其他冲程依靠储能及其他缸的协同完成。
  • 表中按理想化冲程说明；实际存在气门提前开启、延迟关闭等配气时刻。

第 68 页｜二冲程工作循环

课件图示为带火花塞、进排气口及曲轴箱换气的二冲程结构。

  • 第一行程，活塞上行：缸内混合气压缩，曲轴箱吸入新鲜混合气。
  • 上止点附近点火燃烧，随后进入第二行程。
  • 第二行程，活塞下行：燃气膨胀做功，曲轴箱内新鲜混合气受压。
  • 下行后段排气口、扫气口相继开启，进行排气和扫气充填。
  • 一个循环曲轴旋转一周，即 \(360^\circ\)，每缸每循环做功一次。

阅读提示：进排气与其他过程重叠完成；本图结构不能概括所有二冲程发动机。

第 69 页｜汽油机与柴油机比较

本页比较对象是典型四冲程汽油机与柴油机。

项目 汽油机 柴油机
典型关键部件 火花塞 喷油器
进气内容 传统气道供油时为混合气 主要为空气
点火方式 点燃式 压燃式
课件压缩比示例 \(8\sim11\) \(13\sim18\)
每缸工作循环 四冲程、两周、做功一次 四冲程、两周、做功一次
  • 缸内直喷汽油机的进气应结合第 66 页理解，不能套用“都吸入混合气”。
  • 课件将优点简写为汽油机轻便、柴油机便宜且功率大；这些比较依具体机型而变。

第 70 页｜有效转矩与有效功率

  • 有效转矩 \(T_{\mathrm{e}}\)：克服摩擦、附件驱动等损失后，曲轴输出的净转矩。
  • 有效功率 \(P_{\mathrm{e}}\)：曲轴或飞轮对外输出的净功率。

\[ P_{\mathrm{e}}=T_{\mathrm{e}}\omega, \qquad \omega=\frac{2\pi n}{60} \]

采用常用工程单位时：

\[ \frac{P_{\mathrm{e}}}{\mathrm{kW}} \approx\frac{1}{9550} \left(\frac{T_{\mathrm{e}}}{\mathrm{N\cdot m}}\right) \left(\frac{n}{\mathrm{r/min}}\right) \]

\(n\) 为转速；功率等于转矩乘角速度，测得转矩和转速后即可计算功率。

第 71 页｜热效率与有效燃油消耗率

\[ \eta_{\mathrm{t}}=\frac{P_{\mathrm{i}}}{\dot m_{\mathrm{f}}H_{\mathrm{u}}}, \qquad \eta_{\mathrm{e}}=\frac{P_{\mathrm{e}}}{\dot m_{\mathrm{f}}H_{\mathrm{u}}} \]

  • 课件用 \(\eta_{\mathrm{t}}\) 表示指示热效率：燃料热量转变为缸内指示功的比例。
  • 有效热效率：燃料热量转变为曲轴有效功的比例，计入机械损失后更低。
  • \(\dot m_{\mathrm{f}}\) 为燃油质量流量；\(H_{\mathrm{u}}\) 为低位发热量。

\[ \frac{g_{\mathrm{e}}}{\mathrm{g/(kW\cdot h)}} =3.6\times10^6 \left(\frac{\dot m_{\mathrm{f}}}{\mathrm{kg/s}}\right) \left(\frac{P_{\mathrm{e}}}{\mathrm{kW}}\right)^{-1} \]

有效燃油消耗率越低越经济；相同燃料下，它与有效热效率成反比。
